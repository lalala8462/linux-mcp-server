# CentOS 7 compatibility

这是基于 `rhel-lightspeed/linux-mcp-server` 维护的只读 Linux 运维诊断版本，主要增加了 CentOS 6/7 等旧系统的兼容能力，并提供 Windows、WSL 与远程 Linux 服务器之间的受控访问流程。

MCP 主程序运行在 WSL 中，由 WSL 统一管理远程服务器别名、SSH 密钥、主机指纹和访问策略。远程服务器不需要安装完整 MCP 服务，只需要部署专用的 `codex-ro` 账号及只读命令包装器。

## 工作流程

1. Codex Desktop 启动部署在 WSL 中的 Linux MCP Server。
2. 使用者选择一个已经登记的远程服务器别名。
3. MCP 使用该服务器独立的 SSH 私钥连接远程 `codex-ro` 账号。
4. 远程服务器通过 `authorized_keys` 中的公钥完成认证，并强制将请求交给只读命令包装器，不能进入交互式 Shell。
5. 包装器只允许预先定义的系统、服务、进程、网络、磁盘、文件和日志查询命令，并校验命令参数及允许访问的目录。
6. 查询结果通过 SSH 返回 WSL，再由 MCP 提供给 Codex。
7. 安装、卸载或账号清理等需要修改服务器的操作，由本地生成部署包和管理员命令，交给服务器管理员人工审核、执行。

## 安全边界

- 默认只启用 19 个固定只读工具，不开放任意 Shell 或 `run_script`。
- 不使用或保存服务器登录密码、sudo 密码。
- SSH 私钥只保存在 WSL，远程服务器和仓库中只放公钥。
- 每台服务器使用独立密钥、主机指纹和受管别名。
- 未登记的主机默认拒绝访问。
- 文件和日志只能读取管理员批准的单个目录范围，不能配置为根目录 `/`。
- CentOS 6 使用兼容 Python 2.6 的远端包装器，并在显式批准后使用 RSA 4096；CentOS 7/8/Stream 默认使用 Ed25519。


| 类别 | 工具能力 | 典型用途 |
|---|---|---|
| 系统信息 | `get_system_information` | 查看主机名、操作系统、内核版本、运行时间等，快速确认服务器环境。 |
| CPU | `get_cpu_information` | 查看 CPU 型号、核心数、频率等，排查算力或负载问题。 |
| 内存 | `get_memory_information` | 查看物理内存和 Swap 使用情况，定位内存不足、Swap 过高。 |
| 磁盘空间 | `get_disk_usage` | 查看文件系统挂载点、总量、已用和剩余空间，排查磁盘告警。 |
| 硬件 | `get_hardware_information` | 查看 PCI、USB、DMI 等硬件信息，用于设备和虚拟化环境确认。 |
| 服务列表 | `list_services` | 查看系统服务及运行状态，确认服务是否存在、是否启动。 |
| 服务状态 | `get_service_status` | 查看指定服务的详细状态，例如 PID、退出原因和最近状态。 |
| 服务日志 | `get_service_logs` | 查看指定服务的近期日志，定位启动失败、异常退出。 |
| 进程列表 | `list_processes` | 查看全部进程及 CPU、内存占用，定位资源消耗较高的进程。 |
| 进程详情 | `get_process_info` | 根据 PID 查看用户、状态、资源占用、启动参数和运行时间。 |
| 网络接口 | `get_network_interfaces` | 查看网卡、IP 地址和流量统计，排查地址或网卡异常。 |
| 网络连接 | `get_network_connections` | 查看当前 TCP/UDP 连接，排查连接堆积或异常外联。 |
| 监听端口 | `get_listening_ports` | 查看监听端口及对应进程，确认应用是否成功监听。 |
| 系统日志 | `get_journal_logs` | 按服务、级别、时间、日志来源过滤 systemd journal。 |
| 日志文件 | `read_log_file` | 读取批准目录下日志文件的末尾内容，适用于应用日志和传统 CentOS 日志。 |
| 块设备 | `list_block_devices` | 查看磁盘、分区、文件系统和挂载关系，排查磁盘识别或挂载问题。 |
| 目录列表 | `list_directories` | 查看批准路径下的子目录，可按名称、大小或修改时间排序。 |
| 文件列表 | `list_files` | 查看批准路径下的文件，适合查找大文件、最近生成的文件或日志。 |
| 文件读取 | `read_file` | 读取批准范围内的普通文本文件，例如配置、状态文件和业务日志。 |


典型使用场景可以概括为：
- 日常巡检：查看系统版本、CPU、内存、磁盘和服务状态。
- 服务故障：检查服务状态、监听端口、相关进程和服务日志。
- 性能问题：定位高 CPU、高内存进程以及磁盘空间不足。
- 网络问题：检查网卡地址、连接状态和端口监听情况。
- 日志排查：过滤系统日志，或读取批准目录中的应用日志。
- 文件分析：查找最近修改文件、大文件以及读取指定配置文件。
- 多服务器管理：通过受管别名在同一个 MCP 中切换不同远程服务器。

能力边界：
这些工具只能查询，不能启动或停止服务、结束进程、修改配置、写入或删除文件，也不能执行任意 Shell。文件和日志读取还会受到每台服务器 allowed_root 范围、最大读取大小以及远端账号实际文件权限的共同限制。
